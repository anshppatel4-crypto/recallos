## About this repository

This repository hosts the RecallOS installers, the update files the app downloads to keep itself up to date, and its [privacy tests](privacy-tests). The app's source code is private.

- **Verifying a download:** each [release](https://github.com/anshppatel4-crypto/recallos/releases) lists the SHA-256 of its files. The installer isn't code-signed yet, so Windows may warn you when you run it.
- **Updates:** RecallOS checks here and updates itself, so there's nothing to download by hand after installing.
